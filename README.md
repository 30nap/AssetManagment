# داشبورد دارایی‌ها

یک وب‌سایت استاتیک فارسی برای نمایش دارایی‌ها و محاسبه ارزش آن‌ها به تومان، دلار و یورو.

## اجرا

برای اینکه بروزرسانی قیمت‌ها از TGJU کار کند، سایت را با سرور محلی اجرا کنید:

```bash
node server.js
```

بعد این آدرس را باز کنید:

```text
http://127.0.0.1:4173/
```

باز کردن مستقیم `index.html` برای نمایش و محاسبه دستی کار می‌کند، ولی بروزرسانی آنلاین TGJU به خاطر محدودیت CORS مرورگر قابل اتکا نیست.

## بروزرسانی قیمت

دکمه «بروزرسانی آنلاین قیمت‌ها» نرخ‌ها را از صفحه‌های پروفایل TGJU می‌خواند. قیمت‌هایی که TGJU با واحد ریال نمایش می‌دهد در سایت به تومان تبدیل می‌شوند.

سرور محلی `server.js` به عنوان پروکسی امن و کوچک عمل می‌کند و فقط slugهای مشخص‌شده TGJU را می‌خواند. فیلدها همچنان دستی قابل ویرایش هستند.

داده‌های واردشده در `localStorage` مرورگر ذخیره می‌شوند.
